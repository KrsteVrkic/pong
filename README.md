# Pong

A small Pong game built with C++ and raylib.

## Acknowledgment

This game was created with help from AI-assisted tools: ChatGPT and Codex.

## Run

From the repository root, run:

```bash
./dist/pong-linux-x86_64/pong
```

The game loads its audio from `dist/pong-linux-x86_64/assets/audio/`.
