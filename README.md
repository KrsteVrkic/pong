# Pong

A small Pong game built with C++ and raylib.

## Acknowledgment

This game was created with help from AI-assisted tools: ChatGPT and Codex.

## Run

From the repository root, run:

```bash
./dist/pong-linux-x86_64/pong
```

The game loads its audio from `dist/pong-linux-x86_64/assets/audio/`.

## Controls

- Player 1: `W` / `S` to move; hold `Left Shift` to boost.
- Player 2: `Up` / `Down` arrows to move; hold `Right Shift` to boost.
- Super + f: Fullscreen
- Close the game window to quit.
