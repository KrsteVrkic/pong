# Pong

A small Pong game built with C++ and raylib.

## Run

From the repository root, run:

```bash
./dist/pong-linux-x86_64/pong
```

## Controls

- Player 1: `W` / `S` to move; hold `Left Shift` to boost.
- Player 2: `Up` / `Down` arrows to move; hold `Right Shift` to boost.
- Super + f: Fullscreen
- Space: Pause
- Esc: Main Menu
